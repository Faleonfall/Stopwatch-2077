# ⏱️ Stopwatch 2077

![stopwatch](https://github.com/user-attachments/assets/97410ef8-e657-4109-9598-c91e8aca9c38)

A neon stopwatch for the browser, built with Vue 3, TypeScript, Tailwind CSS and GSAP.

## 🟢 Live

[faleonfall.github.io/Stopwatch-2077](https://faleonfall.github.io/Stopwatch-2077/)

## 📲 Shortcuts

- `Space` start or stop
- `R` reset
- `C` copy the time

Clicking the time copies it too. On a phone it can be added to the home screen.
